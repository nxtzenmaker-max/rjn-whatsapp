# RJN WhatsApp API Hub & Baileys Agent

24/7 WhatsApp API Bridge powered by Baileys, MongoDB Atlas, and Railway Cloud Linux execution runner for RJN AI.

## Features
- **Baileys WebSocket Multi-Device**: 24/7 continuous session.
- **Pairing Code Linking**: 8-character linking code without QR scanner requirement.
- **MongoDB Atlas Session Sync**: Credential persistence in `rjn_holo.whatsapp_auth`.
- **Command Runner Integration**: Dispatches terminal commands to `https://rjn-runner-production.up.railway.app`.
- **AI Agent Replies**: Feminine Hindi conversational companion with full database and server access.
